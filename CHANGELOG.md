# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-25

### Added

- `xb2xyz` tool to convert XBeach x.grd / y.grd / *.dep grid files into a *.xyz point file.
- `xyz2xb` tool to convert a *.xyz point file back into x.grd / y.grd / bed.dep files.
- `xbgears` / `xbgears-info` command-line entry points listing available tools.
