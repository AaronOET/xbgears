# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.3.0] - 2026-11-18

### Added

- `xbgen` params.txt builder (tkinter GUI and `--check` / `--write` command line) with the full XBeach keyword database, output lists, range / dependency checks, run.bat writer, and optional .xlsx load / save (`pip install xbgears[xlsx]`).
- `xbclr` tool to remove files generated by an XBeach run (netCDF / Fortran output, logs, generated *.bcf, hotstart files), dry run by default, with `--keep-bc`, `--move-to` and `-r`.

## [0.2.0] - 2026-09-26

### Added

- `xb2yz` tool to convert a 1D XBeach x.grd / *.dep profile into a two-column *.yz file.
- `yz2xb` tool to convert a two-column *.yz file back into 1D x.grd / bed.dep files.

## [0.1.0] - 2026-08-25

### Added

- `xb2xyz` tool to convert XBeach x.grd / y.grd / *.dep grid files into a *.xyz point file.
- `xyz2xb` tool to convert a *.xyz point file back into x.grd / y.grd / bed.dep files.
- `xbgears` / `xbgears-info` command-line entry points listing available tools.
